# โฟลเดอร์ไฟล์เสียง

วางไฟล์เสียงจริงไว้ที่นี่ โดยใช้ชื่อไฟล์ตามนี้ (เกมอ้างอิงจาก `public/js/audio.js`):

| ไฟล์ | ใช้ตอน | แนวเสียงที่แนะนำ |
|------|--------|------------------|
| `bgm.mp3` | เพลงพื้นหลัง (เล่นวนลูป) | สดใส น่ารัก เบาสบาย |
| `correct.mp3` | ทายถูก | ประกาย / ติ๊ง (sparkle, ding) |
| `wrong.mp3` | ทายผิด | บัซเซอร์ / ตุ้บเบา ๆ (soft thud) |
| `slide.mp3` | จั่ว/เลื่อนไพ่, เลือกที่นั่ง | เสียงไพ่เลื่อน (tile slide) |
| `win.mp3` | จบเกม (หน้าผู้ชนะ) | พลุ + เสียงเชียร์ |

ถ้ายังไม่มีไฟล์ เกมยังเล่นได้ปกติ (โค้ดจับ error ของการเล่นเสียงไว้แล้ว จะเงียบเฉย ๆ)

แหล่งเสียงฟรี: freesound.org, pixabay.com/sound-effects, mixkit.co
