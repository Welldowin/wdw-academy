# มนุษย์หมาป่า (One Night Werewolf) — เวอร์ชันไทย

เกมกระดานออนไลน์เรียลไทม์ เล่นได้ 3-10 คนผ่านเบราว์เซอร์ ไม่ต้องสมัครสมาชิก แค่ใส่ชื่อเล่น
สถาปัตยกรรมอ้างอิงจากโปรเจกต์ `DavinciCode` (Express + Socket.io, server-authoritative + เซ็นเซอร์ state รายคน)

---

## 3. สถาปัตยกรรม Socket.io

เซิร์ฟเวอร์ถือ state จริงทั้งหมด (authoritative) ทุก action ตรวจใน `engine.js`
แล้ว **broadcast `room:state` ที่เซ็นเซอร์รายคน** — แต่ละ socket เห็นเฉพาะไพ่ตัวเอง + ข้อมูลที่บทบาทตัวเองมีสิทธิ์เห็นในแต่ละตา

### Client → Server (emit)

| Event | payload | ใช้ตอน |
|---|---|---|
| `room:create` | `{ nickname, playerId }` | สร้างห้องใหม่จากหน้าแรก |
| `room:join` | `{ code, nickname, playerId }` | เข้าห้องด้วยรหัส หรือ reconnect อัตโนมัติ |
| `host:settings` | `{ nightSeconds?, daySeconds?, roleSet? }` | เจ้าของห้องปรับตั้งค่า (เฉพาะตอน lobby) |
| `game:start` | — | เจ้าของห้องเริ่มเกม |
| `setup:ready` | — | กดรับทราบหลังดูไพ่ตัวเอง |
| `night:action` | ขึ้นกับบทบาท (ดู engine.js) | ทำความสามารถตอนกลางคืน / กด "รับทราบ" |
| `day:ready` | — | กดปุ่ม "เริ่มโหวต" |
| `chat:msg` | `{ text }` | แชทตอนกลางวัน |
| `vote:cast` | `{ target: seatNumber \| 'none' }` | โหวต |
| `host:skipVote` | `{ seat }` | เจ้าของห้องข้ามผู้เล่นที่หลุด (งดออกเสียง) |
| `game:restart` | — | เจ้าของห้องเริ่มรอบใหม่ในห้องเดิม |

### Server → Client (emit)

| Event | payload | ความหมาย |
|---|---|---|
| `room:joined` | `{ code, seat }` | ยืนยันการเข้าห้อง |
| `room:state` | state ทั้งก้อน เซ็นเซอร์รายคน | ส่งทุกครั้งที่มีการเปลี่ยนแปลง |
| `sfx` | `{ name }` | ให้ client เล่นเสียง |
| `error:msg` | `{ text }` | แสดง toast |

`room:state` (ย่อ): `phase` (`lobby`/`setup`/`night`/`day`/`vote`/`reveal`), `youSeat`, `youAreHost`,
`players[]` (seat/nickname/connected/isHost/ready), `settings`, `roleCatalog`,
แล้วมี key เฉพาะ phase: `setup` / `night` / `day` / `vote` / `reveal`

## 4. อัลกอริทึมแกนเกม (`src/engine.js`)

### 4.1 แจกไพ่
- Deck = `settings.roleSet` (ความยาวต้อง = ผู้เล่น + 3 ใบ, ต้องมีมนุษย์หมาป่าอย่างน้อย 1 ใบในกอง)
- สับไพ่ (Fisher–Yates) แจกผู้เล่นคนละ 1 ใบ ที่เหลือ 3 ใบเป็นไพ่กลาง

### 4.2 ลำดับกลางคืน (`NIGHT_ORDER` ใน roles.js)
`มนุษย์หมาป่า → สมุนรับใช้ → ผู้หยั่งรู้ → โจร → ผู้ก่อกวน → ขี้เมา → คนนอนไม่หลับ`
ข้ามอัตโนมัติถ้าไม่มีบทบาทนั้นอยู่ในกอง หมดเวลาต่อบทบาท (ตาม `settings.nightSeconds`) ก็ข้ามอัตโนมัติ

### 4.3 โหวต (`resolveVotes`)
- นับคะแนนจากเป้าที่แต่ละคนเลือก (`'none'` หรือเลขที่นั่ง) ไม่นับคนที่ "งดออกเสียง"
- คะแนนสูงสุด ≤ 1 (ไม่มีใครซ้ำกัน) → ไม่มีใครตาย
- ตัวเลือก "ไม่มีหมาป่า" อยู่ในกลุ่มคะแนนสูงสุด → ไม่มีใครตาย
- ไม่งั้น ทุกคนที่ได้คะแนนสูงสุดเท่ากันตายพร้อมกัน
- นายพรานตาย → คนที่นายพรานโหวตไว้ตายตามไปด้วย (กติกาเกมจริง)

### 4.4 ตัดสินผู้ชนะ
- ยาจกตาย → ยาจกชนะ (+ ชาวบ้านชนะด้วยถ้าหมาป่าตายด้วย)
- ไม่งั้น หมาป่าตาย → ชาวบ้านชนะ
- ไม่งั้น ถ้ามีหมาป่าอยู่ในมือผู้เล่น → หมาป่า+สมุนรับใช้ชนะ
- ไม่งั้น (ไม่มีหมาป่าในมือผู้เล่นเลย และไม่มีใครตาย) → ชาวบ้านชนะ

## 5. Dynamic Perspective — ผู้เล่นอยู่ "ล่างสุด" เสมอ

`public/js/render.js` → `seatPosition(mySeat, targetSeat, totalSeats)`:
วางที่นั่งของตัวเองที่มุม 180° (ล่างสุดของวงกลม) ที่เหลือกระจายตามเข็มนาฬิกาตามจำนวนผู้เล่นจริง (3-10 คน)
ไม่ fix 4 ทิศเหมือน DavinciCode เพราะจำนวนผู้เล่นไม่เท่ากันทุกเกม

## 6. ระบบสติ๊กเกอร์สันนิษฐานบทบาท

เก็บเฉพาะเครื่องของผู้เล่นคนนั้น ไม่ sync กับเซิร์ฟเวอร์หรือผู้เล่นอื่น (`public/js/stickers.js`, ใช้ `localStorage`
คีย์ตามรหัสห้อง) แตะที่อวาตาร์ผู้เล่นอื่นหรือไพ่กลางตอนกลางวัน เพื่อแปะไอคอนบทบาทที่สันนิษฐานไว้ ลบล้างทุกครั้งที่เริ่มรอบใหม่

## 7. ข้อจำกัด / ต่อยอดได้

- ยังไม่ใส่ Mason, Doppelgänger, Dream Wolf (ปุ่มเปิด/ปิดใน UI ถูก disable ไว้รอเพิ่มทีหลัง)
- หลุดกลางเกม: รอกลับเข้ามาได้เสมอ (reconnect ด้วย `playerId` ใน localStorage) ยกเว้นตอนโหวตที่เจ้าของห้องข้ามได้หลังรอ 2 นาที
- เจ้าของห้องหลุด: โอนสิทธิ์ให้คนที่เข้าห้องถัดไปตามลำดับที่ยังออนไลน์อยู่
- state อยู่ใน memory (รีสตาร์ตเซิร์ฟเวอร์ = เกมหาย) ห้องที่ไม่มีคนออนไลน์เลยจะถูกลบทิ้งหลัง 10 นาที
- ยังไม่มีไฟล์เสียง/ภาพการ์ดจริง เกมใช้ fallback ไปก่อน ใส่ของจริงได้โดยไม่ต้องแก้โค้ด (ดู README ในแต่ละโฟลเดอร์)
- Lottie (กลางวัน↔กลางคืน, หมาป่าหอน, ประกาศผล) ยังไม่ผูกเข้าโค้ด เพิ่มได้ทีหลังผ่าน dotLottie player
