เครื่องมือวัดละเอียด

ฝึกอ่านค่าเวอร์เนียคาลิปเปอร์ และไมโครมิเตอร์ — ลากสเกลเพื่อสุ่มค่าใหม่ได้
จำนวนขีดเวอร์เนีย:
ลากสเกลล่าง (เวอร์เนีย) เพื่อสุ่มค่าใหม่ • เขียว = ขีด mm ก่อนเลข 0 เวอร์เนีย (ค่าจำนวนเต็ม) • เหลือง = ขีดเวอร์เนียที่ตรงกัน
คะแนน: 0 ถูก / 0 ครั้ง
